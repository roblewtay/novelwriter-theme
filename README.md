## Themes on Mac

Copy theme files to:

```
~/Library/Application Support/novelwriter/themes/
```

Note: novelWriter sometimes changes the theme file format between releases.
If a theme vanishes from Preferences after an upgrade, the file needs updating.

Combine with these Google fonts:

- [EB Garamond](https://fonts.google.com/specimen/EB+Garamond)
- [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond)
